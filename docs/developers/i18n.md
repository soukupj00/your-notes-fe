# Languages

The app ships in English and Czech, with English as the fallback.
It uses [i18next](https://www.i18next.com) with browser language detection, set up in `src/i18n.ts`.

## Where the strings are

Each language is one file, `public/locales/<code>/translation.json`, fetched over HTTP when the app starts and cached by the service worker for offline use.
Components read strings with `useTranslation()` and `t('some.key')`.
A key missing from Czech shows the English text mid-Czech-screen, and a key missing from English shows the raw key.

Every new string ships in both languages, in the same change.

## The bundle test

`src/i18n.test.ts` keeps the bundles honest:

- **Every language has the same keys.**
  Plural suffixes differ by language (Czech adds `_few`), so keys are compared without them.
- **The Tour's strings exist.**
  The Tour composes its keys from the list of steps at render time, so no other check would notice a renamed step.

## Numbers and dates

Format them with the helpers in `src/lib/format.ts`, passing the app's language in.
They wrap `Intl`, so a date or a file size reads the way the language expects.

## Adding a language

1. Copy `public/locales/en/translation.json` to `public/locales/<code>/translation.json` and translate every value.
2. Add the code to `supportedLngs` in `src/i18n.ts`; it is the one list of which languages exist.
3. Give it a name and a flag in `LOCALE_DETAILS` in `src/lib/locales.ts`.
   The name is the language's name for itself, because someone looking for this control may not read the current language.
4. Add the code to `LOCALES` in `src/i18n.test.ts`, then run `pnpm test`.

Settings and the topbar both list languages through `listLocales()`, so the new one appears in both.

The display font covers Latin scripts, including Czech, Polish, Turkish, Vietnamese and German.
Greek, Cyrillic, Japanese and Arabic fall back to the system font, which is fine: [Design](./design.md) explains why titles still read as titles.

## The language is a Device fact

Like every Preference, the language belongs to the Device: it is not in a Backup and it does not sync.
i18next's detector keeps it in `localStorage` itself.
