# M3 Slice 3.5 - Confirm-before-delete retrofit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one shared, media-agnostic confirm-before-delete control and wire it into the image, audio, and video in-editor NodeViews so removing an attachment node always asks first - a small retrofit that changes no deletion timing.

**Architecture:** A single `ConfirmDeleteButton` component under the existing media-agnostic `extensions/attachments/` core renders a `Trash2` trigger plus a confirm `Dialog` (the existing Radix `Dialog` primitive - no new dependency) and calls a supplied `onConfirm` only on confirm. Audio and video swap their bare `onClick={() => props.deleteNode()}` handlers for it; image gains a new (editable-only) delete button routed through the same control. Node deletion stays editor-only (`props.deleteNode()`); blob GC still happens later via `collectOrphans` at dialog close and is untouched.

**Tech Stack:** React 19, TypeScript, TipTap v3 (`@tiptap/core` + `@tiptap/react`), Radix `Dialog` (`src/components/ui/dialog.tsx`), shadcn `Button` (`src/components/ui/button.tsx`), Vitest + React Testing Library + `@testing-library/user-event`, i18next.

## Global Constraints

- Package manager is **pnpm**. `pnpm test`, `pnpm build`, `pnpm check:ci` - never npm/yarn.
- **No new deletion-timing / Dexie logic.** `onConfirm` is always `() => props.deleteNode()` (editor-only). `collectOrphans` at `NoteEditorDialog.tsx:163` is not touched.
- **tsconfig `erasableSyntaxOnly: true`**: no TS constructor parameter-property shorthand; no `enum`/`namespace`.
- **Icons** are string keys resolved through `src/components/icons/icons.ts` via `icons.Trash2` - never import a Lucide component into a button config. `Trash2` is already registered.
- **No em dashes** in code/comments/docs - plain `-`. `@/` import alias. Keep files under 500 lines.
- **i18n**: shared strings live under a new top-level `attachments.confirmDelete.*` in both `public/locales/en/translation.json` and `public/locales/cs/translation.json`; per-kind labels are `editor.image.delete` (new) and the existing `editor.audio.delete` / `editor.video.delete`.
- **Reusable, not media-specific**: the component's props are `{ onConfirm, label, t }` so Slices 4 (files) and 5 (Excalidraw) consume it unchanged.
- Each task lands with its tests + a commit; `pnpm test` + `pnpm build` stay green at every task boundary.

- [x] **Step 4: Implement the component**

Create `src/components/editor/extensions/attachments/ConfirmDeleteButton.tsx`:

```tsx
import { useState } from 'react';
import { icons } from '@/components/icons';
import { Button } from '@/components/ui/button';
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from '@/components/ui/dialog';
import type { TFunction } from '../button-types';

export interface ConfirmDeleteButtonProps {
  /** Invoked once, only when the user confirms. In every NodeView this is
   *  `() => props.deleteNode()` - editor-only, never touches Dexie. */
  onConfirm: () => void;
  /** Per-kind aria-label for the trigger, e.g. t('editor.video.delete'). */
  label: string;
  /** Resolves the shared attachments.confirmDelete.* dialog strings. */
  t: TFunction;
}

/** Shared confirm-before-delete control for media NodeViews (image/audio/video,
 *  and later file/Excalidraw). Renders the Trash2 icon-button trigger and a
 *  confirm dialog; calls onConfirm only on confirm. Node removal stays
 *  editor-only - blob GC still happens at dialog close (collectOrphans). */
export function ConfirmDeleteButton({ onConfirm, label, t }: ConfirmDeleteButtonProps) {
  const [open, setOpen] = useState(false);
  const Trash = icons.Trash2;

  return (
    <Dialog open={open} onOpenChange={setOpen}>
      <DialogTrigger asChild>
        <button
          type="button"
          aria-label={label}
          className="flex size-8 shrink-0 items-center justify-center rounded-full text-muted-foreground hover:bg-destructive/10 hover:text-destructive"
        >
          <Trash className="size-4" />
        </button>
      </DialogTrigger>
      <DialogContent className="sm:max-w-sm">
        <DialogHeader>
          <DialogTitle>{t('attachments.confirmDelete.title')}</DialogTitle>
          <DialogDescription>{t('attachments.confirmDelete.description')}</DialogDescription>
        </DialogHeader>
        <DialogFooter>
          <Button variant="outline" onClick={() => setOpen(false)}>
            {t('attachments.confirmDelete.cancel')}
          </Button>
          <Button
            variant="destructive"
            onClick={() => {
              setOpen(false);
              onConfirm();
            }}
          >
            {t('attachments.confirmDelete.confirm')}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}

export default ConfirmDeleteButton;
```

```tsx
import type { ReactNodeViewProps } from '@tiptap/react';
import { NodeViewWrapper } from '@tiptap/react';
import type { AttachmentDeps } from '../attachments/deps';
import { ConfirmDeleteButton } from '../attachments/ConfirmDeleteButton';
import { useAttachmentObjectUrl } from '../attachments/useAttachmentObjectUrl';

/** Editor render path for imageAttachment. Object-URL lifecycle lives in the
 *  shared useAttachmentObjectUrl hook; delete is guarded by the shared
 *  ConfirmDeleteButton (editor-only, same as audio/video). */
export function ImageNodeView(props: ReactNodeViewProps) {
  const attachmentId = props.node.attrs.attachmentId as string | null;
  const deps = (props.extension.options.getDeps as () => AttachmentDeps)();
  const state = useAttachmentObjectUrl(attachmentId, deps.getAttachment);
  const canDelete = props.editor?.isEditable ?? false;

  const deleteButton = canDelete ? (
    <ConfirmDeleteButton
      onConfirm={() => props.deleteNode()}
      label={deps.t('editor.image.delete')}
      t={deps.t}
    />
  ) : null;

  if (state.status === 'missing') {
    return (
      <NodeViewWrapper as="div" className="my-2" data-drag-handle>
        <div className="flex items-center gap-3 rounded-md border border-dashed p-4 text-muted-foreground text-sm">
          <span className="flex-1 text-center">{deps.t('editor.image.unavailable')}</span>
          {deleteButton}
        </div>
      </NodeViewWrapper>
    );
  }

  return (
    <NodeViewWrapper as="div" className="my-2" data-drag-handle>
      <div className="flex items-start gap-3">
        {state.status === 'ready' && (
          <img
            src={state.url}
            alt={state.name ?? deps.t('editor.image.fallbackAlt')}
            className="h-auto max-w-full rounded-md"
          />
        )}
        {state.status === 'loading' && (
          <div className="h-32 w-full animate-pulse rounded-md bg-muted" aria-hidden />
        )}
        {deleteButton}
      </div>
    </NodeViewWrapper>
  );
}

export default ImageNodeView;
```

(The `missing` branch changes from a plain centered box to the audio/video pattern so the delete button has a home; the `loading` skeleton keeps its behavior but now shares the flex row.)
