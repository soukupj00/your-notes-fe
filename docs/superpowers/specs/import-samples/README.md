# Import sample checklist

## Google Keep (create these in the Keep app, then Google Takeout -> Keep only -> zip)

Create labels `Work` and `Personal` first. Then one note per line; title it exactly as listed so the fixture is easy to read.

| # | Title | What to set |
|---|-------|-------------|
| 1 | Plain | Two paragraphs of text, nothing else |
| 2 | Checklist | List note, 4 items, items 2 and 4 checked |
| 3 | Image | Text + one attached photo |
| 4 | Audio | A recorded voice memo (Keep creates a transcription too) |
| 5 | Archived | Any text, then archive it |
| 6 | Trashed | Any text, then delete it (leave it in trash, do not empty) |
| 7 | Pinned | Any text, pin it |
| 8 | Coloured | Any text, colour Teal; make a second one coloured Red |
| 9 | Labelled | Any text, both labels `Work` and `Personal` |
| 10 | Linked | Paste a URL (e.g. https://example.com) so Keep shows a link preview |
| 11 | Drawing | A Keep drawing (exports as an image) |
| 12 | Empty title | A note with body text and no title |
| 13 | Archived+pinned | Pin it, then archive it (tests that archive clears pin) |
| 14 | Unicode | Title and body with diacritics and an emoji |
